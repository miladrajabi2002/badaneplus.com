# بدنه پلاس | BadanePlus — نسخه ۳ (جاوااسکریپت)

وب‌سایت **[badaneplus.com](https://badaneplus.com)** — ویترین لوازم بدنه خودروهای ایرانی (پژو ۲۰۶، سمند، ۴۰۵/پارس، پراید) + ربات مدیریت کامل تلگرام.

این نسخه کامل پروژه با **جاوااسکریپت** بازنویسی شده است (نسخه قبلی پایتون بود).

---

## معماری — چرا این طراحی سبک است؟

```
┌──────────────┐     استاتیک (HTML/CSS/JS)      ┌──────────────┐
│   کاربر       │ ◄────────────────────────────► │    Nginx     │
└──────────────┘                                └──────┬───────┘
                                                       │ /t و /api/
                                                       ▼ (پراکسی)
                                                ┌──────────────┐
                                                │ Node.js:8083  │
                                                │ Express API   │
                                                │ + ربات grammY │
                                                └──────┬───────┘
                                                       │
                                              ┌────────┴────────┐
                                              ▼                 ▼
                                        SQLite (آمار)      next build
                                        var/badaneplus.db  (خروجی live/)
```

- **سایت**: Next.js 15 با خروجی کاملاً استاتیک — nginx مستقیم فایل HTML را سرو می‌کند؛ **هیچ پروسه‌ای برای نمایش صفحات لازم نیست** → سریع‌ترین حالت ممکن (TTFB ~۳۰ms، حجم صفحه اصلی ~۳۱KB گزیپ)
- **سرور Node**: فقط دو کار سبک — دریافت بیکون آمار (`/t`) + اجرای ربات تلگرام — در یک پروسه PM2
- **دیتابیس**: SQLite (یک فایل: `var/badaneplus.db`) — برای آمار بازدید و بدون نیاز به سرویس اضافه
- **ربات تلگرام**: grammY — مدیریت کامل محصولات، خودروها، وبلاگ، تنظیمات، عکس هیرو و آمار؛ بعد از هر تغییر، سایت خودکار بازسازی می‌شود

## ساختار پروژه

```
badaneplus.com/
├── src/app/          # صفحات Next.js (صفحه اصلی، خودرو، وبلاگ، ۴۰۴، sitemap)

├── public/assets/    # عکس‌ها، فونت‌ها، آیکون‌ها (WebP بهینه)
├── server/           # سرور Node + ربات تلگرام + تست‌ها
│   ├── index.js      # نقطه شروع (API + ربات)
│   ├── bot.js        # هسته ربات
│   ├── bot.products.js / bot.content.js
│   ├── analytics.js  # آمار بازدید (SQLite + شمسی)
│   └── tests/        # ۶۷ تست خودکار
├── data/             # داده‌های سایت (JSON — ربات همین‌ها را ویرایش می‌کند)
├── scripts/          # build-live.sh + verify-build.js
├── deploy/           # کانفیگ nginx + security headers
├── live/             # خروجی نهایی که nginx سرو می‌کند (build شده)
└── var/              # دیتابیس + وضعیت ادمین‌ها (gitignored)
```

## پیش‌نیازها

- Ubuntu 22/24 با دسترسی root
- **Node.js نسخه ۲۰ یا بالاتر** (توصیه: ۲۲ LTS)
- nginx + certbot (SSL)
- PM2 (`npm install -g pm2`)

## نصب از صفر

```bash
# 1) دریافت پروژه
cd /var/www
git clone https://github.com/miladrajabi2002/badaneplus.com
cd badaneplus.com

# 2) تنظیمات محیط
cp .env.example .env
nano .env
#   BOT_TOKEN=توکن ربات از @BotFather
#   BASE_URL=https://badaneplus.com
#   PORT=8083

# 3) نصب وابستگی‌ها + بیلد
npm install
bash scripts/build-live.sh        # بیلد Next.js → live/
node scripts/verify-build.js      # صحت‌سنجی خروجی

# 4) راه‌اندازی (نصب کامل با یک دستور)
bash deploy/setup-server.sh
```

اسکریپت `setup-server.sh` به‌ترتیب: نصب وابستگی‌ها → بیلد → راه‌اندازی PM2 → نصب کانفیگ nginx → تست نهایی.

### SSL (فقط بار اول)

```bash
certbot certonly --webroot -w /var/www/html -d badaneplus.com
systemctl reload nginx
```

## دستورات روزمره

| کار | دستور |
|---|---|
| وضعیت سرویس | `pm2 status badaneplus` |
| **ری‌استارت ربات + API** | `pm2 restart badaneplus` |
| توقف / شروع | `pm2 stop badaneplus` / `pm2 start badaneplus` |
| **مشاهده لاگ‌ها** | `pm2 logs badaneplus --lines 50` |
| **بازسازی دستی سایت** | `bash scripts/build-live.sh` |
| تست‌ها | `npm test` |
| صحت‌سنجی بیلد | `node scripts/verify-build.js` |

> نکته: بعد از تغییر دستی فایل‌های `data/*.json` باید `bash scripts/build-live.sh` اجرا شود تا سایت به‌روز شود. از داخل ربات این کار **خودکار** انجام می‌شود.

## مدیریت از ربات تلگرام (@badaneplusbot)

ربات پنل کامل مدیریت سایت است — هر تغییر، سایت را خودکار بازسازی می‌کند:

- 📦 **محصولات**: افزودن (۸ مرحله هوشمند)، ویرایش همه فیلدها، عکس (تبدیل خودکار WebP)، نمایش/مخفی، ترتیب، حذف
- 🚗 **خودروها**: افزودن (صفحه سئو خودکار ساخته می‌شود)، تغییر نام، ویرایش متن سئو، فعال/غیرفعال
- 📝 **وبلاگ**: افزودن پست با بلوک‌های متن/تیتر/لیست/نکته/جدول، نمایش/مخفی، تغییر عنوان و اسلاگ
- ⚙️ **تنظیمات**: شماره تماس، موبایل، آدرس، ساعات، لینک‌های نقشه (بلد/نشان/گوگل)، مختصات، نام برند
- 🖼 **عکس هیرو**: ارسال عکس → برش خودکار ۳:۴ → WebP دو سایز (۸۶۴×۱۱۵۲ + ۶۴۸×۸۶۴)
- 🎯 **عنوان هیرو**: ۵ پیشنهاد آماده + نوشتن دستی
- 📊 **آمار**: بازدید روزانه/۷روز/ماهانه (شمسی) + بازدید هر مقاله + پربازدیدترین صفحه‌ها

**دسترسی**: اولین کسی که `/start` بزند ادمین می‌شود. برای ادمین‌های بیشتر، شناسه عددی را در `.env` اضافه کنید:
```
ADMIN_IDS=1253939828,111222333
```
و سپس `pm2 restart badaneplus`.

## تغییر عکس هیرو و عنوان (دو راه)

**از ربات (پیشنهادی):** تنظیمات سایت → 🖼 عکس هیرو / 🎯 پیشنهادهای عنوان

**دستی:**
- عکس: فایل `public/assets/img/site/hero-card.webp` (۶۴۸×۸۶۴) و `hero-full.webp` (۸۶۴×۱۱۵۲) را جایگزین کنید → `bash scripts/build-live.sh`
- عنوان: در `data/settings.json` بخش `hero` → `bash scripts/build-live.sh`

**مشخصات عکس هیرو برای طراحان:**
- نسبت **۳:۴ عمودی** (مثلاً ۱۰۸۰×۱۴۴۰ یا ۸۶۴×۱۱۵۲)
- پس‌زمینه تیره با موضوع مرکزی (برش مرکزی خودکار انجام می‌شود)
- فرمت WebP با کیفیت ~۸۰ — هر فایل زیر ۱۰۰KB

## سیستم آمار بازدید

- هر بازدیدکننده یک بیکون سبک به `/t` می‌فرستد (فقط یک‌بار در هر نشست، بدون کوکی)
- ربات‌ها فیلتر می‌شوند؛ تکراری‌ها (IP + صفحه در ۳۰ دقیقه) حذف می‌شوند
- روز و ماه به وقت **تهران** و تقویم **شمسی** محاسبه و ذخیره می‌شود
- داده‌ها در `var/badaneplus.db` (SQLite) — یک فایل، بکاپ ساده

**مشاهده آمار:** ربات → 📊 آمار و وضعیت → 📈 بازدید سایت / 📝 بازدید مقاله‌ها

## بکاپ و ریستور

```bash
# بکاپ (داده سایت + آمار + تنظیمات)
cd /var/www/badaneplus.com
tar czf /root/badaneplus-backup-$(date +%F).tar.gz data/ var/ .env

# ریستور
tar xzf /root/badaneplus-backup-DATE.tar.gz -C /var/www/badaneplus.com/
bash scripts/build-live.sh && pm2 restart badaneplus
```

> ⚠️ فایل `.env` حاوی توکن ربات است — هرگز کامیت نشود (در `.gitignore` است).

## عیب‌یابی

| مشکل | راه‌حل |
|---|---|
| سایت بالا نمی‌آید | `ls live/index.html` — اگر نبود: `bash scripts/build-live.sh` |
| ربات جواب نمی‌دهد | `pm2 logs badaneplus` — اگر توکن خطا داد: `.env` را چک کنید |
| تغییرات ربات در سایت نمی‌آید | `pm2 logs badaneplus` را ببینید؛ دستی: `bash scripts/build-live.sh` |
| خطای ۵۰۲ در /t یا /api | `pm2 status` — اگر offline: `pm2 restart badaneplus` |
| آمار ثبت نمی‌شود | `curl -s http://127.0.0.1:8083/api/health` — فیلد `visits` باید بالا برود |
| پورت اشغال است | `.env` را عوض کنید و در `deploy/badaneplus.com.conf` (دو خط `proxy_pass`) هم تغییر دهید + `systemctl reload nginx` |

## تاریخچه نسخه‌ها

- **v3 (فعلی)**: مهاجرت کامل به جاوااسکریپت — Next.js 15 + grammY + SQLite + PM2
- **v2**: بهبود UX (هیرو یک‌صفحه‌ای، داک موبایل، فوتر سبک) + آمار بازدید + پنج پیشنهاد عنوان — پایتون
- **v1**: نسخه اول — سایت استاتیک Jinja2 + ربات aiogram — پایتون

> کد نسخه‌های قبلی در تاریخچه همین ریپو (کامیت `legacy`) و در `/root/badaneplus-legacy-backup` سرور نگهداری می‌شود.
